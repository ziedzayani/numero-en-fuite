LE NUMÉRO EN FUITE – VERSION WEB

Fichiers générés par « npm run build » à partir de src/ : ne pas modifier index.html ni sw.js à la main.

1) Le plus simple : ouvrez web/Numero_en_Fuite.html dans Chrome Android ou un navigateur récent. Le jeu se lance hors ligne.
2) PWA installable : publiez le contenu de ce dossier sur un hébergement HTTPS, visitez index.html puis utilisez
   « Ajouter à l'écran d'accueil » ou « Installer l'application ». Une PWA ne s'installe pas depuis un fichier local.
3) Application Android : voir README.md (APK compilé automatiquement par GitHub Actions).

LANGUES : français, anglais, arabe (Réglages).
NIVEAUX : Petit 1-9, Moyen 1-15, Grand 1-30, Génie 1-50 ; Défi solo 1-100.
JEU : 1 à 4 personnes, sur un téléphone, sans réseau ni publicités.
